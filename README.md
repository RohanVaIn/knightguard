# knightguard
hackUMBC2026

An educational point-and-click adventure game intended to teach younger children the basics of cybersecurity and get them interested in the field.

# Inspiration
We decided to mix our passion for cybersecurity with our interest in gaming to create an educational experience that would allow kids to learn about cybersecurity in a way that wouldn't overwhelm them. Our game design approach was inspired Purble Place, an old Windows game that came pre-installed.

# What it does
You play as a soldier named Phat Billy, going around a kingdom, helping defend against several medieval-themed cyber threats. You can currently play through a puzzle where you must manage different account permissions of people in the kingdom and a firewall management puzzle where you must determine whether you should allow different peasants in the kingdom

# How we built it
We built it using Java, with drawings in Microsoft Paint

# Accomplishments that we're proud of
We're very proud of the front-end and the puzzle design. Our artist (blewis6) made a very visually appealing system that makes the game a lot more enjoyable to look at. The puzzle design was also an enjoyable and rewarding process, even if we weren't able to accomplish all the puzzles we set out to do.

# What we learned
We learned better project management skills, such as creating realistic scopes and organizing our time and ideas better. We also learned more about Java, as some of our group weren't as familiar with the language as others. Lastly, we learned how to balance the line between entertainment and education, making sure that the lessons weren't subtle enough for kids not to notice, but also subtle enough so that they would stay engaged.

# What's next for KnightGuard
We'd like to add more puzzles in the future, involving concepts such as logging, malware detection, and maybe more advanced topics such as pen testing
